# 🔥 hotservice: پیش‌بینی کندی سرویس‌ها با یادگیری ماشین

این پروژه یک سیستم کامل برای پیش‌بینی مشکلات عملکردی (هات‌اسپات) در سرویس‌های نرم‌افزاری با استفاده از یادگیری ماشین است. به جای تکیه بر هشدارهای سنتی که پس از وقوع مشکل فعال می‌شوند، این سیستم الگوهای متریک‌ها را یاد می‌گیرد تا مشکلات را **قبل از تأثیر بر کاربران** پیش‌بینی کند.

---

## 🏛️ معماری سیستم

این پروژه از چندین جزء مستقل تشکیل شده است که با هم کار می‌کنند:

1.  **جمع‌آورنده متریک (Java/Spring Boot):** سرویسی که متریک‌های خام (زمان پاسخ، CPU، حافظه و...) را از سرویس اصلی دریافت و در دیتابیس ذخیره می‌کند.
2.  **دیتابیس (PostgreSQL):** برای ذخیره‌سازی متریک‌های خام و داده‌های تجمیع‌شده.
3.  **برنامه آموزش مدل (Python):** یک برنامه پایتون که به صورت دوره‌ای اجرا می‌شود، داده‌ها را از دیتابیس می‌خواند، آن‌ها را برچسب‌گذاری کرده و یک مدل `RandomForestClassifier` را آموزش می‌دهد.
4.  **برنامه پیش‌بینی زنده (Python):** یک برنامه جداگانه که آخرین نسخه مدل را بارگذاری کرده و به صورت زنده (هر ۵ ثانیه) با استفاده از جدیدترین داده‌ها، احتمال هات‌اسپات شدن سرویس در ۱۵ دقیقه آینده را پیش‌بینی می‌کند.

---

## 🎯 بیان مسئله: فراتر از مانیتورینگ سنتی

ابزارهای مانیتورینگ سنتی معمولاً از **آستانه‌های ایستا (Static Thresholds)** استفاده می‌کنند (مثلاً `CPU > 90%`). این رویکرد دو مشکل اساسی دارد:

- **هشدارهای کاذب (False Positives):** افزایش CPU در زمان اوج ترافیک ممکن است طبیعی باشد اما باعث هشدار غیرضروری شود.
- **مشکلات پنهان (False Negatives):** مشکلات پیچیده مانند نشت حافظه (Memory Leak) ممکن است به صورت آرام و با ترکیب چندین متریک رخ دهند و هیچ‌گاه یک آستانه را به تنهایی فعال نکنند.

این پروژه با یادگیری **الگوهای چندبعدی** بین متریک‌ها، این خلاء را پر می‌کند.

---

## 🛠️ تکنولوژی‌های استفاده شده

- **بک‌اند:** Java 17, Spring Boot 3
- **دیتابیس:** PostgreSQL
- **یادگیری ماشین:** Python, Pandas, Scikit-learn

---

## ⚙️ نحوه اجرا

برای اجرای این پروژه به صورت محلی، مراحل زیر را دنبال کنید:

1.  **پیش‌نیازها:** مطمئن شوید Java، Python و PostgreSQL روی سیستم شما نصب هستند.
2.  **راه‌اندازی دیتابیس:** یک دیتابیس به نام `hsp` در PostgreSQL بسازید.
3.  **اجرای سرویس‌های جاوا:** پروژه بک‌اند را باز کرده و سرویس جمع‌آوری متریک و سرویس خود را اجرا کنید، به آدرس http://localhost:8080/metrics متریک هارو ارسال کنید.
4.  **آموزش مدل:** اسکریپت `trainer_script.py` را اجرا کنید تا اولین نسخه مدل آموزش داده شود.
5.  **شروع پیش‌بینی:** اسکریپت `predictor_script.py` را اجرا کنید تا پیش‌بینی‌های زنده را مشاهده کنید.
